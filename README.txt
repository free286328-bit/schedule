Lunary 설치 안내

1. 이 폴더의 모든 파일을 HTTPS 정적 호스팅(Netlify Drop, GitHub Pages 등)에 함께 업로드하세요.
2. 아이폰 Safari에서 배포된 URL을 열고 공유 > 홈 화면에 추가를 선택하세요.
3. Android Chrome에서는 메뉴 > 앱 설치(또는 홈 화면에 추가)를 선택하세요.
4. 데스크톱에서는 Chrome/Edge의 설치 아이콘을 이용하세요.

주의: index.html 파일을 기기에서 직접 열면 PWA 설치 및 오프라인 기능이 작동하지 않을 수 있습니다.
데이터는 브라우저의 localStorage에만 저장됩니다. 설정 > 백업 파일 저장을 주기적으로 이용하세요.
서버 동기화/푸시 알림은 제공되지 않습니다.
